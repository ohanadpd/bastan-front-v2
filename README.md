## معرفی پروژه

پلتفرم کاشی و سرامیک یک سکوی چندزبانه و ماژولار برای ساخت وب‌سایت‌های شرکت‌های تولید و فروش کاشی و سرامیک است.

### ✨ ویژگی‌های کلیدی
- **چندزبانه:** پشتیبانی از فارسی، انگلیسی و عربی
- **مدیریت محصولات:** نمایش، فیلتر و جستجوی محصولات
- **نمایندگی‌ها:** سیستم مدیریت نمایندگان
- **مقالات و اخبار:** بخش محتوایی تخصصی
- **فرصت‌های شغلی:** سیستم مدیریت استخدام
- **سفارش‌گیری:** سبد خرید و پرداخت
- **پنل کاربری:** مدیریت حساب کاربری

## 🛠️ پشته فناوری

### هسته اصلی
| تکنولوژی | نسخه | کاربرد |
|----------|------|--------|
| Next.js | 15.1.9 | فریمورک اصلی |
| React | 19 | رابط کاربری |
| TypeScript | 5 | تایپ‌سیف |

### UI و استایل
- **Tailwind CSS** – استایل‌دهی
- **Radix UI** – کامپوننت‌های دسترسی‌پذیر
- **Swiper** – اسلایدر
- **Framer Motion** – انیمیشن

### مدیریت حالت
- **Zustand** – استیت مدیریت
- **Formik + Yup** – فرم‌ها و اعتبارسنجی

### ابزارهای جانبی
- **Axios** – ارتباط با API
- **Lingui** – بین‌المللی‌سازی
- **Next Auth** – احراز هویت
- **React Leaflet** – نقشه

## 🚀 راه‌اندازی

### پیش‌نیازها
- Node.js (نسخه LTS)
- Git

### مراحل نصب

```bash
# کلون کردن ریپازیتوری
git clone [repository-url]
cd kashi-platform

# نصب وابستگی‌ها
npm install

# کپی فایل محیطی
cp .env.example .env.local

# اجرای پروژه
npm run dev
```

### 🔧 فایل‌های محیطی
| فایل | هدف |
|------|-----|
| `.env.local` | توسعه عمومی |
| `.env.nikceram.local` | محیط نیک سرام |
| `.env.emarat.local` | محیط امارات |
| `.env.arg.local` | محیط آرگ |
| `.env.bastan.local` | محیط باستانی |
| `.env.nafis.local` | محیط نفیس |

## 🏗️ معماری

### معماری Feature-Based
- **`components/products/`** – کامپوننت‌های محصولات
- **`components/auth/`** – کامپوننت‌های احراز هویت
- **`components/profile/`** – کامپوننت‌های پروفایل
- **`components/cart/`** – کامپوننت‌های سبد خرید

### مدیریت حالت
- **Zustand Stores** برای داده‌های سراسری
- **React State** برای داده‌های محلی
- **Formik** برای مدیریت فرم‌ها

### سرویس‌ها
```typescript
// مثال: سرویس محصولات
src/lib/services/products.services.ts
src/lib/services/cart.services.ts
src/lib/services/auth.services.ts
```
